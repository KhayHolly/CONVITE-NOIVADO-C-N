# Convite de Noivado — Narcisio & Catarina

Projeto pronto para publicação no GitHub Pages.

## Publicação

1. Crie um repositório no GitHub.
2. Envie **todos os ficheiros e pastas** desta pasta, mantendo `assets/musica.mp3` dentro de `assets`.
3. Em **Settings → Pages**, selecione a branch principal e a pasta `/ (root)`.
4. Guarde e abra o endereço fornecido pelo GitHub Pages.

O ficheiro principal é `index.html`.
